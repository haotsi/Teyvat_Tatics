# problem_2.md 更新反馈文档

## 本次更新概述

根据 `problem/problem_2.md` 的反馈，本次更新修复了 4 个核心问题并实现了多项功能改进，共涉及 12 个修改点。

---

## 一、Bug 修复

### 1. 合成面板拖入修复（🔴 P0）
- **问题**：棋子拖入合成槽位后，若关闭面板则棋子永久丢失；同一棋子可被拖入两个槽位
- **修复**：
  - 拖入槽位时仅记录引用（不删除原棋子），点击"合成"时才真正删除
  - 添加引用去重机制：同一棋子不可同时出现在两个槽位中
  - 关闭面板或点击"× 关闭"按钮仅清空槽位引用，不删除任何棋子
  - 合成完成后新棋子自动进入储存栏

### 2. 武器卸下逻辑修复（🔴 P0）
- **问题**：卸下武器后自动装备默认 2 星武器，导致可无限卸下刷武器
- **修复**：
  - 卸下武器后角色进入"无武器"状态，ATK 计算中武器部分为 0
  - 已无武器时无法再卸下（按钮不显示）
  - 详情面板显示"武器: 无"（灰色文字）

### 3. 储存栏棋子点击查看详情（🟡 P1）
- **问题**：点击储存栏棋子无法查看详情面板
- **修复**：短点击（无拖拽）时触发 `clicked` 信号，在 InfoPanel 显示角色信息

### 4. 商店锁定功能（🟡 P1）
- **问题**：锁定按钮从未创建
- **修复**：每个商店商品卡片添加 🔒/🔓 锁定按钮，锁定商品在刷新时保留
- **刷新逻辑**：`Shop::refresh()` 已正确实现锁定保留（move→clear→move back 模式）

## 二、功能改进

### 5. 合成面板 & 背包嵌入主窗口（🟡 P1）
- **问题**：面板作为独立弹窗可能超出屏幕
- **修复**：面板作为主窗口内嵌部件，通过按钮切换显隐
- **操作**：
  - 点击"背包"按钮 → 面板在储存栏下方展开
  - 点击"命之座合成"按钮 → 合成面板在下方展开
  - 点击面板右上角"× 关闭"按钮或再次点击按钮 → 面板隐藏

### 6. 装备拖放功能（🟡 P1）
- **功能**：从背包拖放武器/圣遗物到角色详情面板的装备区
- **操作步骤**：
  1. 点击"背包"按钮打开背包面板
  2. 点击棋子查看角色详情
  3. 从背包拖拽武器到角色详情中"武器"下方的拖放区（虚线框）→ 装备成功
  4. 从背包拖拽圣遗物到对应槽位（花/羽毛/沙漏/杯子/皇冠）下方的拖放区 → 装备成功
  5. 若角色已有装备，旧装备自动返回背包
- **提示**：拖放区为虚线框，拖入时会高亮显示

### 7. 商店角色预览模式（🟡 P1）
- **功能**：点击商店中的角色仅预览属性，不可操作装备
- **效果**：商店角色详情不显示"卸下"按钮、"出售"按钮和装备拖放区
- **对比**：储存栏/棋盘上的角色详情可正常进行装备操作

### 8. 背包实时刷新（🟡 P1）
- **功能**：背包自动同步数据变化
- **触发时机**：
  - 购买武器/圣遗物后
  - 出售背包物品后
  - 装备/卸下武器/圣遗物后
  - 打开背包时（通过 `showEvent` 主动刷新）

### 9. 出售角色按命座定价（🟡 P1）
- **新价格公式**：90 原石（基础价）+ 15 × 命之座等级
- **示例**：
  | 命之座 | 售价 |
  |--------|------|
  | 0 命   | 90 原石 |
  | 1 命   | 105 原石 |
  | 3 命   | 135 原石 |
  | 6 命   | 180 原石 |
- 出售按钮显示价格，如 "出售 (105原石)"

### 10. 战斗日志优化（🟡 P1）
- **改进**：单区域 + `[我方]`/`[敌方]` 前缀区分
- 我方伤害：绿色 `[我方]` 前缀
- 敌方伤害：红色 `[敌方]` 前缀
- **过滤按钮**：
  - "全部"：显示所有日志
  - "我方"：仅显示我方造成伤害
  - "敌方"：仅显示敌方造成伤害

### 11. AI 逻辑优化（🟢 P2）
- 减少避战行为：超载惩罚降低（*0.5 → *0.8）
- 当前位置可达攻击目标时不移动
- 低血量目标优先：HP<30% 额外 +30 分
- 移除随机移动行为（不再无意义跑动）

## 三、已有功能的操作说明

以下功能已在之前版本中实现，但可能不易发现：

| 功能 | 操作方法 |
|------|---------|
| 部署棋子到棋盘 | 从储存栏**拖拽**棋子到棋盘第 5-8 行（我方区域） |
| 棋盘棋子移动 | 在棋盘上**拖拽**棋子到其他位置 |
| 撤回棋子到储存栏 | 将棋子**拖回**储存栏，或点击详情面板"撤回储存栏"按钮 |
| 右键出售背包物品 | 在背包物品上**右键** → 选择"出售" |
| 右键移除合成槽位 | 在合成槽位上**右键** → 清空该槽位 |
| 商店物品详情 | **点击**商店商品卡片 → 左侧显示详情 |
| 升级人口 | 点击详情面板"升级人口"按钮 |
| 开始战斗 | 部署棋子后点击"开始战斗"按钮 |
| 难度选择 | 左侧面板顶部下拉菜单 |
| 存档/读档 | Ctrl+S 保存 / Ctrl+L 读取 |

## 四、与 design.md 的新增规则

以下规则在 `design.md` 中未明确定义，本次更新中新增：

1. **武器可完全卸下**：角色可处于"无武器"状态，此时 `hasWeapon() = false`，ATK 计算不含武器部分。角色构造函数仍默认装备匹配职业的 2 星武器。
2. **角色出售价格**：`90 + 15 × 命之座等级` 原石（不再使用 `CHARACTER_COST * SELL_RATIO`）。
3. **合成消耗规则**：合成消耗两个旧棋子（从储存栏或棋盘永久移除），生成新棋子。新棋子命之座 = a + b + 1（上限 6）。
4. **装备拖放**：装备可通过背包 → 角色详情面板的拖放操作进行装备，无需额外按钮。
5. **商店锁定**：锁定商品在刷新时保留，不会被替换。
