## v0.1.1 (当前版本) — problem_4.md 更新

### 本次更新概述

修复 7 个 Bug + 实现 2 项功能：元素反应系统、装备匹配、长柄武器穿刺、战斗拖动安全、背包容量调整、死亡棋子状态、储存栏满提示、存档系统完善。

### 验证公式结果

所有反应公式与 design.md **完全一致**：
- 增幅精通区：`(2.8×EM)/(EM+1400)`
- 激化精通区：`(5×EM)/(EM+1200)`
- 剧变精通区：`(6×EM)/(EM+1400)`
- 剧变常数：`800`
- 伤害公式：`ATK×(反应倍率+精通区)×技能倍率×(1+暴伤)×(1+增伤)`

### 一、Bug 修复

#### 1. 元素反应系统修复（🔴 CRITICAL）

**问题**：`checkReactionBetween` 排序后使用未排序变量名比较，导致 9 种反应中仅蒸发可用。结晶位于不可达代码块。烈绽放不伤友方。

**修复**：
- 重写全部 9 个反应条件为排序后比较
- Geo 不再附着元素，结晶检查移出 `size<2` 限制
- 烈绽放 `splashDamage` 改为 2（伤害敌+友）
- 暴击判定在日志和伤害间共享同一 RNG

#### 2. 装备匹配（🔴）

**问题**：任何角色可装备任何武器；任何圣遗物可放入任何槽位。

**修复**：
- `equipWeapon`：检查 `weapon.type() == piece.weaponType()`
- `equipArtifact`：检查 `artifact.slot() == targetSlot`
- 拖放时类型不匹配直接拒绝（无高亮）

#### 3. 长柄武器穿刺伤害（🔴）

**问题**：`getValidAttackTargets` 收集线上所有敌人但只攻击一个。

**修复**：`processCharacterAction` 中长柄武器遍历攻击方向上线所有敌人（最大距离 2）。

#### 4. 战斗拖动崩溃（🔴）

**问题**：战斗中拖动棋子时修改棋盘，导致战斗循环崩溃。

**修复**：
- `BoardWidget` 拖放事件添加 `phase != Preparation` 检查
- `PieceItem` 鼠标事件添加 phase 检查 + 死亡棋子不可交互

#### 5. 背包容量调整（🟡）

**问题**：引擎容量 20 vs UI 显示 10；自动出售机制与设计不符。

**修复**：
- 容量统一为 10
- 移除 `enforceBackpackCapacity` 及自动出售
- 购买/装备/卸下前检查容量，满则拒绝并提示

#### 6. 死亡棋子状态（🟡）

**问题**：死亡棋子正常占据格子，阻挡移动，可被交互。

**修复**：
- `Board::isOccupied`：死亡棋子返回 false
- `playerPieces/enemyPieces`：过滤死亡棋子
- `PieceItem::paint`：死亡时透明度 0.3
- 死亡棋子不可拖动/点击

#### 7. 储存栏满提示（🟡）

**问题**：储存栏满时静默退款。

**修复**：添加 `messageLogged` 提示"储存栏/背包已满"。

### 二、新功能：存档系统完善

存档现在保存完整游戏状态：
- 储存栏角色（含武器、圣遗物、HP、能量、命座）
- 棋盘角色（含位置、装备）
- 武器背包和圣遗物背包

### 三、本次操作指南

| 操作 | 方法 |
|------|------|
| 装备匹配 | 拖放时会自动检查类型——不匹配的装备不会高亮接受 |
| 长柄穿刺 | test_4（长柄武器）可同时攻击一条线上的所有敌人 |
| 查看背包物品详情 | **单击**背包中的武器/圣遗物 → 左侧显示详情 → 可出售 |
| 存档 | Ctrl+S → 选择保存位置 → 完整保存角色/装备/背包状态 |

## v0.1.0 — problem_3.md 更新

### 崩溃修复

1. **AI 战斗闪退**：`findBestPosition` 信号风暴 → Board 信号抑制 + AI 向敌移动
2. **装备拖放闪退**：EquipDropRow use-after-free → 角色 ID 查找 + `QTimer::singleShot` 延迟回调
3. **合成闪退**：QVector 索引偏移 → 先移除高索引角色

### 新功能

1. **合成装备管理**：合成前自动卸下双方全部装备，新角色空装备。`createMergedCharacter` 替代旧逻辑。
2. **背包容量**：武器 20 件、圣遗物 20 件（v0.1.1 改为 10），超出自动出售（v0.1.1 改为拒绝并提示）。
3. **角色出售价格**：`90 + 15×命座` 原石。

### 操作指南

| 操作 | 方法 |
|------|------|
| 装备武器 | 打开背包 → 角色详情 → 拖拽武器到虚线框 |
| 装备圣遗物 | 打开背包 → 角色详情 → 拖拽圣遗物到对应槽位虚线框 |
| 卸下武器 | 角色详情中点击武器旁的"卸下" |
| 卸下圣遗物 | 角色详情中点击对应圣遗物旁的"卸下" |
| 合成 | 打开合成面板 → 拖入两个同名角色 → 点击"合成升星" |
| 右键背包出售 | 背包物品上 **右键** → 出售 |
| 右键槽位清空 | 合成槽位上 **右键** → 清空 |

## v0.1.0-alpha — problem_2.md 更新

### 核心修复

1. **合成面板**：从独立弹窗改为内嵌 widget，添加关闭按钮，延迟删除（不丢棋子），引用去重
2. **武器卸下**：`clearWeapon()`，角色可无武器，ATK 检查 `m_hasWeapon`
3. **储存栏点击**：`mouseReleaseEvent` 区分拖拽/点击
4. **商店锁定**：每个商品卡片添加 🔒/🔓 按钮

### 功能改进

- 合成面板 & 背包嵌入主窗口（按钮切换显隐）
- 装备拖放（EquipDropRow 拖放区）
- 商店角色预览模式
- 背包实时刷新（`backpackChanged` + `showEvent`）
- 战斗日志 `[我方]/[敌方]` 前缀 + 过滤按钮
- AI 优化：减少避战、增加攻击倾向

### 操作指南

| 功能 | 方法 |
|------|------|
| 部署棋子 | 从储存栏 **拖拽** 到棋盘第 5-8 行 |
| 移动棋子 | 在棋盘上 **拖拽** 到其他位置 |
| 商店物品详情 | **单击** 商品卡片 |
| 锁定商品 | 点击 🔒/🔓 按钮 |
| 战斗日志过滤 | 点击"全部"/"我方"/"敌方"按钮 |
