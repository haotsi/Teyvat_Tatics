# problem_3.md 更新反馈文档

## 本次更新概述

根据 `problem/problem_3.md` 的反馈，本次更新修复了 3 个导致游戏闪退的严重崩溃 Bug，并实现了合成装备管理机制和背包容量限制系统。

---

## 一、崩溃修复

### 1. AI 战斗闪退修复（🔴 根因：信号风暴）

**问题根因**：`findBestPosition()` 的评估循环中临时移动/移除棋子时，每次操作都会触发 `boardChanged()` 信号 → `refreshBoard()`（删除并重建所有 QGraphicsObject）。8 个候选位置 × 每位置 4 次信号 = 每棋子每回合 32 次信号发射。加上 AI 在无攻击目标时也不移动导致战斗陷入永久僵局，信号风暴持续累积，最终损坏 Qt 图形管道内部状态导致闪退。

**修复内容**：
- `Board` 类新增 `m_signalBlocked` 标志和 `setSignalBlocked(bool)` 方法
- 所有 `emit boardChanged()` 调用均检查 `m_signalBlocked`，阻止时跳过
- `findBestPosition()` 评估循环前后设置/清除信号阻塞
- `chooseMove()` 新增"向最近敌人移动"逻辑：当所有位置均无攻击目标时，向曼哈顿距离最近的敌人移动一步

### 2. 装备拖放闪退修复（🔴 根因：使用后释放）

**问题根因**：`EquipDropRow::dropEvent()` 中调用 `m_onEquipped()` → `showCharacterInfo()` → `clearLayout()` **删除当前正在执行 dropEvent 的 EquipDropRow 对象本身** → `this` 变为悬空指针 → 函数返回时访问已释放的内存 → 闪退。

**修复内容**：
- `EquipDropRow` 改用基于 ID 的角色查找（`m_pieceId` 替代原始 `m_piece` 指针）
- `GameEngine` 新增角色注册表（`m_characterRegistry`，`QHash<int, CharacterBase*>`）
- `CharacterBase` 新增全局唯一持久 ID（`m_persistentId`），构造时自动分配
- `GameEngine::registerCharacter()` / `unregisterCharacter()` / `findCharacterById()` 方法
- `addToStorage()` 和 `sellStorageItem()` 中调用注册/注销
- 回调改为 `QTimer::singleShot(0, ...)` 延迟执行，确保 `dropEvent()` 在有效 `this` 上完成后才重建 UI

### 3. 合成闪退修复（🔴 根因：索引偏移）

**问题根因**：当两个角色都来自储存栏时，先 `takeFromStorage(slotA.index)` 移除角色 A 会导致 QVector 缩小，B 槽位的原始索引变为错误值。如果索引越界，`takeFromStorage` 返回 `nullptr`——角色 B 从未从储存栏移除。随后 `delete b` 释放内存，但 `m_storage` 中的悬空指针在下一次访问时引发 segfault。

**修复内容**：
- `performMerge()` 中当两个角色都来自储存栏时，**先移除较大索引的角色**（索引大的移除不影响索引小的）
- 混合来源（储存栏+棋盘）按原顺序处理，互不影响

## 二、新功能

### 1. 合成装备管理机制

**功能说明**：点击合成时，系统自动处理装备管理：

1. **卸下双方装备**：两个参与合成的角色的武器和所有圣遗物自动卸下并放入对应背包
2. **删除原角色**：从储存栏或棋盘移除两个原角色并释放
3. **创建新角色**：生成同名、空装备的新角色，命之座 = a.命座 + b.命座 + 1（上限 6）
4. **加入储存栏**：新角色自动进入储存栏；若储存栏已满则提示无法合成

**注意**：合成后的新角色不继承原角色的任何装备，所有装备均返回背包。如需为新角色装备，请使用背包拖放功能。

### 2. 背包容量限制 + 自动出售

**功能说明**：
- 武器背包容量：**20 件**
- 圣遗物背包容量：**20 件**
- 超出容量时自动出售价值最低的物品：
  - 按出售价格（`sellPrice()`）从低到高出售
  - 同价格按加入顺序（下标从小到大）出售
  - 出售所得摩拉自动加入余额
  - 战斗日志中显示"已自动出售 [物品名]，获得 X 摩拉"

**触发时机**：
- 购买武器/圣遗物
- 卸下角色装备
- 合成时卸下双方装备
- 任何物品进入背包时自动检查

### 3. 商店角色预览模式

点击商店中的角色时，详情面板仅显示预览（不可操作装备）。点击储存栏或棋盘上的角色时，可进行装备拖放和卸下操作。此功能在前次更新中已实现。

## 三、操作指南

### 装备操作

| 操作 | 方法 |
|------|------|
| 为角色装备武器 | 打开背包 → 打开角色详情 → 从背包**拖拽武器**到角色详情中"武器"下方的虚线框 |
| 为角色装备圣遗物 | 打开背包 → 打开角色详情 → 从背包**拖拽圣遗物**到对应槽位（花/羽毛/沙漏/杯子/皇冠）下方的虚线框 |
| 替换装备 | 直接拖拽新装备到已有装备的角色槽位 → 旧装备自动返回背包 |
| 卸下武器 | 在角色详情中点击武器旁的"卸下"按钮 |
| 卸下圣遗物 | 在角色详情中点击对应圣遗物旁的"卸下"按钮 |
| 查看背包物品详情 | **单击**背包中的武器/圣遗物 → 左侧显示详情 → 可点击"出售"按钮出售 |
| 右键出售背包物品 | 在背包物品上**右键** → 选择"出售" |

### 合成操作

| 操作 | 方法 |
|------|------|
| 打开合成面板 | 点击"命之座合成"按钮 |
| 放入角色 | 从储存栏或棋盘**拖拽角色**到合成面板的角色A/角色B槽位 |
| 移除角色 | 在槽位上**右键**清空 |
| 执行合成 | 确认两个角色同名 → 点击"合成升星"按钮 |
| 关闭面板 | 点击"× 关闭"按钮或再次点击"命之座合成"按钮 |

### 商店操作

| 操作 | 方法 |
|------|------|
| 锁定商品 | 点击商品卡片上的 🔒/🔓 按钮 → 锁定后刷新时保留 |
| 查看商品详情 | **单击**商品卡片 → 左侧显示预览（角色预览模式下不可操作装备） |
| 刷新商店 | 点击"刷新"按钮（消耗摩拉） |

### 战斗日志

| 操作 | 方法 |
|------|------|
| 查看全部日志 | 点击"全部"按钮 |
| 仅查看我方伤害 | 点击"我方"按钮 |
| 仅查看敌方伤害 | 点击"敌方"按钮 |

## 四、与旧版本的差异说明

1. **角色现在可完全无武器**：卸下武器后 ATK 计算不含武器部分。角色创建时仍然自动装备匹配职业的 2 星武器。
2. **合成不再保留装备**：旧版本合成会选择较高星级武器/圣遗物保留给新角色。新版本中所有装备先卸下、新角色空装备。
3. **背包有容量上限**：武器 20 件、圣遗物 20 件。超出时自动出售最低价值物品。
4. **角色出售价格**：`90 + 15 × 命之座等级` 原石。
