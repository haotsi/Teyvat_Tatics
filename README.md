项目描述：以《原神》为原型的自走棋游戏



一、开发环境与语言：



qtcreator【qt6】（C++）平台PC



游戏内自然语言：简体中文



二、核心玩法与战斗机制：



1、对战模式：单人PVE（玩家仅在准备阶段布阵，战斗阶段AI自动控制棋子移动与攻击。需要设计AI评分函数：攻击高威胁目标、凑羁绊、避免被反应等，难度可调参数。）；



2、游戏进程：每轮分为：准备阶段（购买、调整站位、装备）→ 战斗阶段。战斗阶段共比赛11轮，当对手场上棋子全部被消灭算本轮胜利，11局6胜制。



3、棋盘布局：8\*8初始场地均分为两个部分，敌方在上半场为1-4行，我方在下半场为5-8行，部署时只能在我方区域部署棋子，但棋子的行动不受其影响，格子为矩形；



4、棋子设定：对于一方阵营，按棋子顺序先后编号为1-4，移动和攻击均按编号从小到大的顺序。入场一回合定义为一方的行动回合，此时一方所有棋子先移动一格（可选），移动可以朝上下左右以及对角线八个方向，然后对范围内一名敌人攻击（可选）。一方所有棋子按编号依次行动完毕后，另一方再行动。一枚棋子包含其单独存在时具有的属性以及其入场后的队伍属性：

元素反应类{

机制介绍：游戏中每一个角色拥有一个特定的元素类型，任意攻击一次（\*）敌人会给敌人挂上一单位该次攻击对应元素附着对应的元素（\*\*）（敌人可被挂元素总上限为三单位，该上限的溢出为队列的形式，即先进先出，后进后出；一个单位的附着持续三个回合，三个回合后该单位元素附着消失），如上文中刻晴对敌人进行一次攻击将会给敌人挂上一单位雷元素。当某敌人已经被挂上一单位某元素时，一位或两位己方角色对该敌人又进行了一次或两次攻击，且此时敌人身上的两个或三个单位元素可反应（在后文将介绍），将消耗掉这两个或三个单位元素，并对敌人触发特殊反应效果，下面介绍两种特殊反应效果：增幅反应和剧变反应；并介绍角色的元素精通属性对这两种特殊反应伤害的增幅（增幅系数伤害公式中用精通区表示）。注意：对于对手来说，我们即为文本中的敌人，所以对手也能对我方棋子产生元素反应，造成相应伤害和效果。

\------------------------------------------------

（\*）特别的，风元素角色攻击不带任何元素的敌人时不会给敌人挂上单位风元素，但当敌人身上已存在单位可与风元素发生反应的元素时（见后文扩散反应），可触发扩散反应且不会消耗敌人原有的元素附着

（\*\*）如过该次攻击对应的元素附着为（无），则不会给敌人挂上任何元素

\------------------------------------------------

(1)增幅反应(Scaling Reactions):通过提升原始伤害的比例生效，受触发角色（\*\*\*）攻击力、暴击率、暴击伤害、元素伤害加成、元素精通等属性影响，但需要注意：大招无法触发增幅反应。

I)蒸发：伤害倍率为1.8倍

II)融化：伤害倍率为1.8倍

增幅反应伤害为：name.dmg\*（增幅反应伤害倍率+精通区），即：

如果暴击：角色攻击力\*（增幅反应伤害倍率+精通区）\*（1+暴击伤害）\*（1+元素伤害加成）；

如果不暴击：角色攻击力\*（增幅反应伤害倍率+精通区）\*（1+元素伤害加成）；

暴击的概率即暴击率。



(2)剧变反应(Transformative Reactions)：生效时，造成额外独立伤害，或者额外的效果（不影响原始伤害），剧变反应伤害只由触发角色的元素精通、该剧变反应类型的剧变反应倍率和角色反应常数（为800）决定，则剧变反应伤害为：800\*剧变反应倍率\*（精通区+1）

I)超载（火+雷）：剧变反应倍率为3.0，触发时将产生一次爆炸（要有特效），使该敌人后退一格（当敌人后方有棋子或敌人已在棋盘边界时不后退）

II)感电（水+雷）：剧变反应倍率为2.0，触发时与该棋子相邻（只考虑上下左右）的敌方棋子受到一次剧变反应倍率为0.5的伤害（视为剧变反应）

III)超导（冰+雷）：剧变反应倍率为1.5，触发时与该棋子相邻（只考虑上下左右）的敌方棋子受到一次剧变反应倍率为0.6的伤害（视为剧变反应）

IV)冻结（水+冰）：不产生剧变反应伤害，但可使敌人冻结（应有冻结特效），使受到冻结的敌人下一回合无法行动

V)扩散（风+水/雷/火/冰）：剧变反应倍率为0.8，且不会消耗敌人原有的元素附着，触发时与该棋子相邻（只考虑上下左右）的敌方棋子受到一次剧变反应倍率为0.4的伤害（视为剧变反应），且会为这些敌方棋子挂上一单位对应元素。例如下面的部分棋盘：

||A（我方）||
|-|-|-|
|C（敌人）|D（敌人：已有一单位火元素）|B（敌人）|
||E（我方）||

本回合内若对D进行风元素攻击，造成一次风元素伤害，并对D造成倍率为0.8的剧变反应伤害，对BC造成倍率为0.4的剧变反应伤害；且元素附着情况为：

||A||
|-|-|-|
|C（一单位火元素）|D（一单位火元素）|B（一单位火元素）|
||E||

VI)绽放及相关反应{

1)原绽放（水+草）：在敌人所在格子上生成一枚草种子（需要有建模），若草种子本回合内未被火雷元素激活（即后文的烈绽放和超绽放），则在下一回合即敌人回合爆炸，对草种子所在格子上的任何棋子（己方或敌方）造成倍率为1.0的剧变反应伤害，并对与草种子所在格子相邻的敌方棋子产生倍率为1.0的剧变反应伤害，相邻的己方棋子产生倍率为0.6的剧变反应伤害

}

VII)激化及其相关反应{

1)原激化（雷+草）：不触发剧变反应，但将消耗一单位雷元素一单位草元素，使敌人进入激化状态持续3个回合（2个己方回合，1个敌方回合）

2)蔓激化（激化状态+草）：退出激化状态，但不消耗触发该反应所需草元素，对敌方造成一次倍率为2.5的剧变反应伤害

VIII)燃烧反应（火加草）：剧变反应倍率为0.8，但将持续2回合造成剧变反应伤害，该伤害无视结晶反应产生的护盾，且会消耗一单位火元素和一单位草元素，每回合生成一单位火元素（溢出规则参考本类开头介绍）

三、商店，人口与升星系统

商店：商店中会出售圣遗物（随机类型，对应类型的随机有效词条），随机类型（随机品质，品质越高的武器出现概率越低）的武器，随机的角色。

所有商店每回合开始时自动刷新（免费），后续玩家可用摩拉刷新（第一次50，随后每次加25，每回合重置价格）

增加锁定按钮：保留当前商品不刷新



金币系统：初始为320原石（本作购买角色的金币），1000摩拉（本作购买装备和圣遗物的金币），每一局获胜方得320原石，1000摩拉；失败方得160原石，500摩拉.

物价：角色160原石一个；圣遗物100摩拉一个；武器二星50摩拉一个，每升一星涨50摩拉（即五星需要200）

利息：每回合不论输赢均可获得当前拥有的10%的原石和摩拉利息



人口：每位角色占用一个人口，在棋盘上，一方初始最多可有两个人口，可用160原石升级一次增加到3人口，上限为4人口；同时每方均有可容纳10个人口的储存栏。购买棋子后，棋子首先进入储存栏，然后玩家从储存栏将棋子拖上场。



背包系统：允许自由拖拽替换，卸下的装备和圣遗物进入背包，可以将废弃的装备和圣遗物按商店价格的1/4（向下取整）出售。



升星系统：上文提到的命之座即为本游戏的星级系统，将任意一个命之座等级为a（0<=a<=6）与同一个角色命之座等级为b（0<=b<=6）的棋子合在一起可以合成命之座等级为(a+b+1)的一个对应角色

棋子。若a+b+1大于六，则在合成前提醒玩家，并提供一个取消合成，一个确认合成的选项，若玩家选择确认合成，则生成一个六命的棋子。命之座的效果在上文中命之座类提到了，上文为刻晴的效果，每个角色效果不同。
